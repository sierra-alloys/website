# SIERRA INC. GitHub Pages Website

Files are ready for GitHub Pages.

## Upload
Upload all files/folders in this package to the root of:
`sierra-alloys/website`

Required:
- index.html
- style.css
- script.js
- CNAME
- assets/

## GitHub Pages
Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

## Custom domain
The included `CNAME` file contains:
`sierra-alloys.com`

In GitHub Settings → Pages → Custom domain, enter:
`sierra-alloys.com`

## Gabia DNS
After the GitHub site works on the default GitHub Pages URL, replace the old Gabia forwarding records with GitHub Pages DNS records. Do not delete future iCloud Mail MX/TXT records.

## Before final launch
Update:
- email address in index.html if desired
- actual office address
- product portfolio / business descriptions
